# Offline verification

These are future native acceptance steps, not passing tests for this shell. A web export or TypeScript check cannot prove Android FTS5 or inference.

1. Build Android with the real adapters. Intentionally provision an attributed starter pack and compatible licensed GGUF.
2. Prove FTS5 and local model initialization before disabling connectivity.
3. Test with an embedded JavaScript bundle. A Metro-connected development build depends on the development host.
4. Enable airplane mode, turn Wi-Fi off, and search `renewable energy`. Open the actual stored passage.
5. Ask three supported questions. Inspect streaming and every citation; only retrieved source IDs may resolve.
6. Ask an unsupported question; show missing evidence without fabricated claims or sources.
7. Import TXT/Markdown with a unique phrase, search for it, and cite it. Force-close/restart; check documents, saves, searches, and chats persist.
8. Delete with confirmation. Check results, bookmarks, and citations for stale records; retain the external original.
9. Test missing/corrupt models, insufficient RAM, invalid queries, duplicates, unsupported PDFs, invalid packs, and storage errors.
10. Audit network traffic. Local search/import/inference must have no HTTP dependency. Record device, ABI, RAM, build, corpus/model versions, timings, and failures.
11. Check Android back, safe areas, keyboard behavior, large text, TalkBack labels, contrast, and touch targets.
